# amedas-rain — 気象庁公式データで雨量・警報・WBGTを引く Claude スキル

日本の任意の地名（例:「東京」「千葉」）を指定すると、気象庁 (JMA) の公式エンドポイントから
**日別降水量・最新の10分/1時間/24時間積算・現況の警報/注意報・気象台の見通し文・
現場座標の1kmメッシュ解析雨量とキキクル・推定WBGT（暑さ指数）** を取得します。
民間天気サイトのスクレイプは行わず、出典は気象庁と環境省の公式データのみです。

## 使い方（Claude に話しかける）

- 「千葉の直近7日の雨量」
- 「東京で警報が出そうか見て」（`--outlook`）
- 「北緯35.68 東経139.77 の真上の解析雨量とキキクル」（`--site lat,lon`）
- 「東京の今日の暑さ指数」（`--wbgt`）
- 「〒260-0013 の雨量と警報」（郵便番号→最寄り観測所を自動選択。`--site` を付けるとその住所の真上1kmメッシュ）

スキルは同梱の `scripts/jma_amedas.py` を実行します。手動実行も可能です:

```bash
python3 scripts/jma_amedas.py 千葉 --days 7
python3 scripts/jma_amedas.py 千葉 --outlook --pref 千葉
python3 scripts/jma_amedas.py 東京 --site 35.681,139.767
python3 scripts/jma_amedas.py 東京 --wbgt --days 7
python3 scripts/jma_amedas.py 260-0013 --outlook --site   # 郵便番号
```

## このプラグインが行う通信・保存（すべて開示）

| 動作 | 内容 |
|---|---|
| 取得 (HTTPS GET) | `www.jma.go.jp/bosai/*`（AMeDAS速報値・観測所マスタ・警報JSON・概況・防災タイル PNG）、`www.data.jma.go.jp`（防災情報XMLフィード・etrn過去統計）、`www.wbgt.env.go.jp`（環境省WBGT実況CSV、`--wbgt` 時のみ）、`zipcloud.ibsnet.co.jp`（郵便番号→住所）と `msearch.gsi.go.jp`（国土地理院 住所→座標）は**郵便番号を指定した時のみ** |
| 保存 | 観測所マスタ `amedastable.json` を `scripts/` フォルダ内にキャッシュ（初回のみ） |
| 送信 | なし。個人データの収集・外部送信は一切行いません |
| 認証 | 不要 |

## 要件

- Python 3.8 以上（標準ライブラリのみ）。`--site` の1kmメッシュ判読のみ `Pillow` が必要です（未導入なら `pip install Pillow`）

## 制約

- 雨量は**速報値**（約7〜10日分）。正式統計が必要な場合は気象庁の確定値ページを参照してください
- 当日分は10分値のコマ数が揃うまで過小表示になり、その場合 `※Nコマのみ` と注記します
- 警報の「解除時刻」は予測しません（土壌雨量指数の残留のため）
- `--wbgt` は簡易式による**推定値**です。さらに、値は**アメダス観測所の気温・湿度から算出**したもので、指定した地名・郵便番号の場所そのものの観測ではありません。近隣であっても地形・日射・舗装で数度ずれるため、**あくまで参考程度**にとどめ、屋外作業の管理は現地の黒球付きWBGT計の実測を正としてください。対応地点は東京・千葉・長崎(一部)（`WBGT_PROXY` に地点を追記すると拡張できます）
- 警報 JSON の府県コードは `--pref` で指定します（既定は東京 130000）

## Privacy

- **収集**: このプラグインは個人データを収集・保存しません。処理するのは、ユーザーが入力した地名・郵便番号・座標だけです
- **送信先**: 気象庁 (`jma.go.jp`) および環境省 (`wbgt.env.go.jp`) の公開データを取得します。郵便番号を指定した場合のみ、郵便番号を zipcloud (`zipcloud.ibsnet.co.jp`)、得られた住所を国土地理院 (`msearch.gsi.go.jp`) に送って座標化します。各サービスの取り扱いは各社のポリシーに従います
- **保持**: 作者側にサーバーはなく、Claude から受け取るデータを一切保持しません。ローカルに残るのは観測所マスタのキャッシュ (`scripts/amedastable.json`) のみです
- **第三者提供**: ありません
- **連絡先**: https://github.com/okura1234/claude-plugins/issues
