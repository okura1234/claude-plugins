# 1kmてんき (amedas-rain) — 郵便番号・住所・位置情報で「その場所」の雨・警報・暑さ指数を引く Claude スキル

> **非公式**: 本プラグインは個人開発であり、気象庁 (JMA)・環境省とは一切関係ありません。取得するデータの出典が公的機関であるというだけです。

郵便番号・住所・位置情報（緯度,経度）・地名のどれか一つを指定すると、気象庁の公開エンドポイントから
**その場所の真上1kmメッシュの解析雨量とキキクル（浸水・洪水・土砂の警戒レベル）・最寄りアメダスの日別降水量と最新値・
市町村の警報/注意報・気象台の見通し文・推定WBGT（暑さ指数）** を取得します。

## 入力の種類と精度

| 入力 | 1kmメッシュ（雨・警戒レベル） | 雨量・WBGT | 警報・注意報 |
|---|---|---|---|
| **位置情報** `35.6812,139.7671`（スマホのGPS値など） | **その地点の真上** | 最寄りアメダス観測所（距離を表示） | その地点の市区町村 |
| **郵便番号** `260-0013` | その郵便番号の**代表点**の真上（同じ番号内でも離れた場所は別メッシュになりうる） | 同上 | 住所の市区町村 |
| **住所** `長野県松本市丸の内3` | 住所の代表点の真上 | 同上 | 同上 |
| **地名** `東京` | 使いません（`--site 緯度,経度` を付ければ可） | その名前のアメダス観測所 | `--pref` の府県で名前照合 |

現場のピンポイントが要るなら位置情報、手軽さなら郵便番号、という使い分けです。

**スマホの現在地を使うには**: https://okura1234.github.io/claude-plugins/ を開いて「現在地を取得する」→「Claude に貼る文をコピー」→ Claude に貼り付け。このページは位置情報を画面に表示するだけで、どこにも送信・保存しません（静的HTML 1枚・通信処理なし）。Claude 自身は端末のGPSにアクセスできないため、この手順が必要です。雨量とWBGTはいずれも
**最寄りのアメダス観測所の観測**であり、その場所そのものの値ではありません。
民間天気サイトのスクレイプは行わず、出典は気象庁と環境省の公式データのみです。

## 使い方（Claude に話しかける）

- 「千葉の直近7日の雨量」
- 「東京で警報が出そうか見て」（`--outlook`）
- 「北緯35.68 東経139.77 の真上の解析雨量とキキクル」（`--site lat,lon`）
- 「東京の今日の暑さ指数」（`--wbgt`）
- 「〒260-0013 の雨量と警報」（郵便番号→最寄り観測所を自動選択。`--site` を付けるとその住所の真上1kmメッシュ）
- 「35.6812,139.7671 の現況」（位置情報。`--site` でその地点の真上1kmメッシュ）
- 「長野県松本市丸の内3 の警報」（住所）

スキルは同梱の `scripts/jma_amedas.py` を実行します。手動実行も可能です:

```bash
python3 scripts/jma_amedas.py 千葉 --days 7
python3 scripts/jma_amedas.py 千葉 --outlook --pref 千葉
python3 scripts/jma_amedas.py 東京 --site 35.681,139.767
python3 scripts/jma_amedas.py 東京 --wbgt --days 7
python3 scripts/jma_amedas.py 260-0013 --outlook --site   # 郵便番号
```

## このプラグインが行う通信・保存（すべて開示）

| 動作 | 内容 |
|---|---|
| 取得 (HTTPS GET) | `www.jma.go.jp/bosai/*`（AMeDAS速報値・観測所マスタ・警報JSON・概況・防災タイル PNG）、`www.data.jma.go.jp`（防災情報XMLフィード・etrn過去統計）、`www.wbgt.env.go.jp`（環境省WBGT実況CSV、`--wbgt` 時のみ）、`zipcloud.ibsnet.co.jp`（郵便番号→住所）は郵便番号指定時のみ、`msearch.gsi.go.jp`（国土地理院 住所→座標）と `mreversegeocoder.gsi.go.jp`（国土地理院 座標→市区町村コード）は郵便番号・住所・位置情報の指定時のみ |
| 保存 | 観測所マスタ `amedastable.json` を `scripts/` フォルダ内にキャッシュ（初回のみ） |
| 送信 | なし。個人データの収集・外部送信は一切行いません |
| 認証 | 不要 |

## 要件

- Python 3.8 以上（標準ライブラリのみ）。`--site` の1kmメッシュ判読のみ `Pillow` が必要です（未導入なら `pip install Pillow`）

## 制約

- 雨量は**速報値**（約7〜10日分）。正式統計が必要な場合は気象庁の確定値ページを参照してください
- 当日分は10分値のコマ数が揃うまで過小表示になり、その場合 `※Nコマのみ` と注記します
- 警報の「解除時刻」は予測しません（土壌雨量指数の残留のため）
- `--wbgt` は簡易式による**推定値**です。さらに、値は**アメダス観測所の気温・湿度から算出**したもので、指定した地名・郵便番号の場所そのものの観測ではありません。近隣であっても地形・日射・舗装で数度ずれるため、**あくまで参考程度**にとどめ、屋外作業の管理は現地の黒球付きWBGT計の実測を正としてください。全国のアメダス地点に対応します（気温・湿度の観測がない地点は最寄りの観測所で代替し、その旨を表示）
- 警報 JSON の府県コードは郵便番号指定時は住所から自動決定、地名指定時は `--pref` で指定します（既定は東京 130000）

## Privacy

- **収集**: このプラグインは個人データを収集・保存しません。処理するのは、ユーザーが入力した地名・郵便番号・住所・座標だけです
- **送信先**: 気象庁 (`jma.go.jp`) および環境省 (`wbgt.env.go.jp`) の公開データを取得します。郵便番号を指定した場合は郵便番号を zipcloud (`zipcloud.ibsnet.co.jp`) に送って住所化し、郵便番号・住所・位置情報のいずれかを指定した場合は住所または座標を国土地理院 (`msearch.gsi.go.jp` / `mreversegeocoder.gsi.go.jp`) に送って座標化・市区町村コード化します。各サービスの取り扱いは各社のポリシーに従います
- **保持**: 作者側にサーバーはなく、Claude から受け取るデータを一切保持しません。ローカルに残るのは観測所マスタのキャッシュ (`scripts/amedastable.json`) のみです
- **第三者提供**: ありません
- **連絡先**: https://github.com/okura1234/claude-plugins/issues
