1kmてんき 現在地の取得

スマホの位置情報から緯度・経度を取り出して、Claude に貼るためのページです。

このページが行うこと・行わないこと
  • ボタンを押したときだけ、この端末の位置情報（緯度・経度）を取得します。ブラウザが許可を求めるので、許可してください。
  • 取得した位置情報はこの画面に表示するだけで、どこにも送信・保存されません。このページにはサーバーも通信処理もありません（静的なHTML 1枚です）。
  • Claude に渡すのは、表示された数値をあなた自身がコピーして貼り付けた分だけです。
  • それ以外の情報（連絡先・写真・端末情報など）には一切アクセスしません。
確認したい方へページのソースを表示すると、通信を行うコードが含まれていないことを確認できます。ソースは GitHub で公開しています。

使い方
  1. 「現在地を取得する」を押して、ブラウザの位置情報を許可する
  2. 「Claude に貼る文をコピー」を押す
  3. Claude（1kmてんき を入れた状態）に貼り付けて送る
精度は端末とGPSの状況次第です（屋内では数百mずれることがあります）。1kmメッシュの判定には十分ですが、ずれが気になる場合は取得し直してください。
